# EKKE Desktop — Releases

Windows installer downloads for **EKKE Catalog Studio** (desktop app).

- **Download the latest:** see **Releases** on the right, grab the `.exe` under Assets, run it.
- SmartScreen may warn (unsigned build): **More info → Run anyway**.
- First launch downloads the AI models once (~1.5 GB); after that it runs offline.
- Installed copies **auto-update** from new releases here.
